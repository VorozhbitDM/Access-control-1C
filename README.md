## ⚡ Ключевые возможности

| Область | Что умеет обработка |
|---------|---------------------|
| 🔍 **Анализ прав** | Связи пользователь ↔ роль ↔ группа ↔ профиль ↔ объект метаданных в одном окне |
| 🌳 **Дерево метаданных** | Полная структура конфигурации, поиск по имени и синониму |
| ⚖️ **Сравнение** | Роли, группы, профили между собой; права двух пользователей; копирование прав |
| 📊 **Отчёты по ролям** | «Роли без пользователей», «Роли вне профилей» — сводные метрики и детализация |
| 🔎 **Парсер запросов** | Анализ таблиц участвующих в запросе и проверка прав пользователя на доступ |
| 👤 **Мониторинг** | Сеансы, журнал регистрации, автопоиск ошибок прав доступа |
| ⚙️ **Управление** | Включение в группы, создание профилей, ограничения доступа, история изменений |
